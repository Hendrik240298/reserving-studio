# Skill Promotion Request

Use this template when you want to turn a useful workflow into a reusable skill.

```text
Please turn this into a skill.

Name:
Use when:
Use these existing tools:
Inputs:
Expected output:
Stop rules:
What it must not do:
Should discovery docs be updated too? yes/no
Additional notes:
```

## Minimal Required Guidance

If you want to keep it short, these are the most important fields:

- Name
- Use when
- Use these existing tools
- Stop rules
- What it must not do

The harness should ask only for missing high-impact fields rather than re-asking for everything.
